## 🚀 Featured Projects

### 1. Teacher Management System
A comprehensive management system developed for Genius Aulad Skudai to digitize and streamline administrative operations. The platform integrates modules for teacher record management, leave tracking, task and duty assignment, training progression monitoring, and automated reporting to enhance operational efficiency.

### 2. Recoverable Assets & Inventory Risk Management (IRM) Pipeline
An end-to-end data pipeline built on Microsoft Azure that extracts unstructured manufacturing inventory files and processes them through a multi-layer Medallion architecture. The solution transforms raw records into an automated Power BI dashboard that proactively identifies real-time stockout risks and material expiration alerts.

### 3. Brazilian Government Education Census ETL Pipeline
A scalable ETL pipeline that ingests 2.2 GB of unstructured public census CSV data using Apache Spark (PySpark). The data is transformed, compressed into Parquet files, and loaded into a Star Schema relational database for optimized analytical querying and reporting.

### 4. Vehicle Emissions & Fuel Efficiency Analysis
An exploratory data analysis project that ingests automotive datasets and processes them using Python and Pandas. The project includes data cleaning, transformation, and generation of interactive visualizations using Matplotlib and Seaborn to uncover patterns and trends in vehicle emissions and fuel efficiency.
